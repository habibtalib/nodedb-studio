per auth mode (CONN-01/02), force a handshake via an identity-probe round-trip, derive real

in-session secret into a live `ActiveConnection`. All async lands here, at the seam.

on `NodeDbConnectionService`, and a disconnect/release path — with unit tests for client build,
OIDC PoolConfig, error mapping, and disconnect.

       }
